# entities-scene-morning-in-a-cafe

A cafe scene for the social VR world, as an engine project with the avatar and map add-ons it loads.

## What it is for

It places an anime-style cafe model as a world map and loads avatars into it through the world's add-ons.

## Open it

Clone it with its submodules, then open `project.godot` in the engine editor and run the main scene.
